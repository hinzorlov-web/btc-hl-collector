# btc-hl-collector

Ежедневные снимки позиций BTC на Hyperliquid — для столпа 3 индекса
(«какая сторона ближе к маржин-коллам»). У Hyperliquid нет истории
позиций, поэтому пропущенный день восстановить нельзя: сбор идёт в облаке,
независимо от ноутбука.

## Как работает

- **Каждый день в 00:10 UTC** (03:10 по Москве) Supabase будит GitHub
  Actions (`repository_dispatch`, тип `hl_collect`).
- **Резерв** — собственное расписание GitHub в 00:40 UTC. Если снимок за
  сутки уже есть, повтор пропускается.
- **Ежедневно** опрашиваются 2000 крупнейших счетов таблицы лидеров и все
  держатели BTC из последнего полного опроса (≈ 10 мин).
- **По воскресеньям** — полный опрос всех счетов (≈ 95 мин); он обновляет
  список держателей `data/hl_known.json`.
- Сборщик **только сохраняет** позиции, открытый интерес и цену. Столп 3
  считается на ноутбуке (нужна дневная волатильность с Binance, а Binance
  серверам GitHub отказывает).

## Где данные

- `data/hl/ГГГГ/ММ/hl_ГГГГММДД_ЧЧММ_daily.json.gz` — снимки (сжатый JSON);
  `_full` — полный опрос.
- `data/hl_known.json` — держатели BTC из последнего полного опроса.
- `data/hl_log.csv` — журнал: время, режим, сколько счетов, позиций,
  ошибок, минут, покрытие лонгов и шортов.

## На ноутбуке

```
py btc_hl_stops.py sync               — забрать новые снимки в hl_snapshots/
py btc_hl_stops.py recompute latest   — столп 3 по последнему снимку
```

## Запустить вручную

Вкладка **Actions** → **hl-collect** → **Run workflow** → режим `auto`,
`daily` или `full`.

Код и правила — `btc_hl_stops.py`; описание проекта — PROJECT.md
(проект «Шортсквиз крипторынка Августа 2026»).
